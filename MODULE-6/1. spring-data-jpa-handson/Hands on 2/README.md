# Exercise 2 - Hibernate XML Configuration

## Objective

This exercise focuses on understanding Hibernate XML Configuration and the core components of the Hibernate Framework.

## Topics Covered

- Object Relational Mapping (ORM)
- Hibernate XML Configuration
- SessionFactory
- Session
- Transaction
- beginTransaction()
- commit()
- rollback()
- session.save()
- session.createQuery().list()
- session.get()
- session.delete()

## Note

This exercise is theory-based and does not require any code implementation.
